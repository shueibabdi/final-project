# Todo App

A simple and clean Flutter To-Do application for managing daily tasks.

## About

Todo App allows users to create tasks, view their tasks, and mark completed tasks. The project is built with Flutter and Dart.

The main purpose of this project is to practice Flutter development while following a real Git and GitHub workflow.

## Features

* Add new tasks
* View tasks
* Mark tasks as completed
* Simple and clean user interface
* Responsive mobile design

## Technologies

* Flutter
* Dart

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/shueibabdi/final-project.git
```

Navigate to the project:

```bash
cd final-project
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
